A powerful CLI-based tool to test SMS OTP sending mechanisms via PHD endpoint. Designed for educational and testing purposes only.

## ✨ Features

- 🎨 **Beautiful CLI Interface**: Color-coded output and ASCII banners.
- ⚡ **Powerful**: Fast execution with customizable delay.
- 🛡️ **Input Validation**: Prevents invalid number formats.
- 📝 **Detailed Logs**: Real-time status updates for each request.

## 📦 Installation

### Windows

1. Install [XAMPP](https://www.apachefriends.org/index.html).
2. Add `php` to your System Environment Variables (Path).
3. Clone or download this repository.

### Linux / macOS

```bash
sudo apt-get install php-cli php-curl curl  # Debian/Ubuntu
# or
brew install php  # macOS
```

## 🚀 Usage

Run the script via terminal:

```bash
php phd.php
```

Follow the on-screen prompts:

1. **Target Number**: Enter number starting with country code `62` (e.g., `628123456789`).
2. **Amount**: How many times to send.
3. **Delay**: Time (in seconds) to wait between requests.
